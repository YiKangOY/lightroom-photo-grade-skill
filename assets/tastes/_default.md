# Default photographic taste

- Prefer a natural, restrained result that still feels deliberately graded.
- Protect highlight rolloff; avoid brittle whites and obvious HDR compression.
- Allow a gently anchored black point, while preserving useful shadow separation.
- Keep neutrals believable unless the current instruction explicitly asks for a color cast.
- Keep skin alive and dimensional; avoid orange skin, magenta contamination, and plastic uniformity.
- Restrain electric blues and synthetic greens. Preserve color hierarchy instead of maximizing saturation.
- Favor coherent relationships across a set over forcing identical numeric settings.
- Show one representative pilot before applying a batch.
